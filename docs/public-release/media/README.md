# 국감 라이브 홍보 자산

제작물은 독립 앱의 기능을 설명하기 위한 합성 데모다. 실제 운영 화면·회의 원문·인명·원음·계정을 사용하지 않았다. 국회 공식 앱·공식 인증 또는 자동 판단의 정확도를 주장하지 않는다.

- `gukgam-live-threads-30s.mp4`: 한국어 내레이션·음악·한글 화면 자막을 포함한 최종 세로 영상. 1080×1920, 30.037초, 약 8.61MB.
- `poster.png` / `poster.svg`: 1080×1920 포스터, 편집 가능한 벡터 원본.
- `promo-script.ko.txt`: 한국어 내레이션 원고.
- `promo.ko.srt`: 별도 자막. 문장 단위 편집 타이밍이며 자동 단어 정렬 파일은 아니다.
- `promo-canvas.html` / `render-motion.mjs`: 검수한 합성 UI·애니메이션의 제작 원본과 로컬 MP4 렌더러.
- `promo-motion-master.mp4`: 기존 격리 브라우저의 MediaRecorder로 렌더한 무음 모션 원본.
- `storyboard.md`: 스토리보드와 기능 표현 범위.
- `render-brand.mjs`: 설치된 sharp 런타임으로 아이콘·포스터를 재현하는 로컬 제작 소스. 도구 설치·네트워크·운영 자료 접근 없음.

최종 영상은 1080×1920/9:16으로 한국어 내레이션·생성 배경음악을 합성했다. 원본 클립 음성은 사용하지 않는다. 최종 MP4의 대표 7개 시점에서 한글·합성 UI·자막 여백을 확인했다. 디코딩한 48kHz/스테레오 PCM 표본 피크는 -4.89dBFS이며 full-scale 이상 표본은 0개다. 이는 LUFS·오버샘플 true-peak 또는 발음 청취 평가와 다르다. 상세 수치는 `audio-review.json`, 파일 해시는 `deliverables.sha256.json`에 있다.

온라인 제작 도구의 임시 다운로드 주소·서명 토큰·job ID·결제 내역은 이 디렉터리에 기록하지 않는다. 첫 유료 모션 결과는 글씨 배치 검수에서 제외했고, 해당 파일·제작 입력·검수 프레임은 ignored 작업 자료에만 보존한다. 최종 영상에는 사용하지 않는다.

아이콘 원본과 Windows ICO는 `desktop/assets/brand/`에 있다. 소셜 계정 연결·Threads 게시 작업은 하지 않았다.
