# 검색과 시간바, 질의 요약을 보여 주는 앱 소개영상

1080×1920 / 9:16 / 한국어. 계정 연결을 시작으로 검색·시간바 탐색·질의 요약·자료 요구와 약속·보고서 내보내기를 실제 앱 화면으로 보여 줍니다.

**바이브코딩 몰라도 내 GPT 계정으로 국정감사 회의록 정리**

| 장면 | 핵심 문구 | 보여 줄 기능 |
| --- | --- | --- |
| 도입 | 내 GPT로, 국감 정리 시작. | ChatGPT 데스크톱 연결을 선택한 계정 사용 설정 |
| 검색 | 필요한 발언, 검색해서 바로 찾기 | 검색어 입력·결과 건수·해당 문장 강조 |
| 기록 탐색 | 하단 시간바로 발언을 빠르게 오가기 | 시간바 클릭·드래그와 가까운 시각의 기록 발언 이동 |
| 질의 요약 | 질의별 자동 요약을 질의자별로 모아 보기 | 위원별 이름 아래 질의 회차를 펼친 발언내용 요약 |
| 다음 할 일 | 자료 요구와 약속을 한곳에서 | 후속조치 내용·담당 부서·기한·처리 상태 |
| 보고서 | 찾고 정리한 기록을 보고서로 | 단독 HTML·문서·텍스트·CSV 내보내기 |
| 마무리 | 바이브코딩 몰라도 내 GPT 계정으로 국정감사 회의록 정리 | 검색·시간바·요약 핵심 화면과 제품명 |

사용 흐름은 **데스크톱 앱의 AI 연결에서 로그인 → 자막·녹음 선택 → 발언 검색 → 시간바 탐색 → 질의자별 요약 확인 → 자료 요구·약속 정리 → 보고서 내보내기**입니다.

시간바는 기록 발언으로 이동하는 기능으로 보여 줍니다. 요약은 질의 블록별 생성 결과를 질의자별·회차별로 모아 보여 줍니다. 화면에 보이는 검색 결과·시간·요약을 활용하고, 장면 전환은 실제 조작 흐름에 맞춥니다.

마지막 장면은 검색·시간바·요약 화면과 함께 “바이브코딩 몰라도 내 GPT 계정으로 국정감사 회의록 정리”를 화면과 내레이션에 담습니다. 기능 설명 외의 고지성 오버레이는 추가하지 않습니다.

기본 소개 자산은 `gukgam-live-product-tour.mp4`와 `poster-product-tour.png`입니다. 장면 길이와 내레이션·자막은 완성된 소개영상에 맞춥니다.
