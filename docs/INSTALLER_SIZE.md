# 0.2.0 경량 인터넷 설치 구성 · 준비 중

0.2.0은 필요한 기능을 처음 쓸 때 준비하는 인터넷 설치 방식입니다. 아직 최종 배포 용량·설치 후 크기·검증 완료 수치는 확정하지 않았습니다. 작은 설치 실행파일과 실제로 내려받는 전체 용량은 구분해 안내합니다.

| 시점 | 준비하는 내용 | 다시 사용할 때 |
|---|---|---|
| 처음 설치 | 시작 화면·계정 연결·사용설명서가 담긴 기본 앱 | 설치된 기본 앱 사용 |
| 기록 화면을 처음 열 때 | 전체 Python 기록 엔진과 필요한 실행 환경 | 검증된 같은 판본 재사용 |
| 중계 연결·사이트 준비를 처음 누를 때 | 고정 Vercel CLI 50 기반 중계 도구와 사이트 기본 자료 | 검증된 같은 판본 재사용 |
| 음성·추가 역할 기능을 준비할 때 | 선택한 음성 모델·CPU 실행 도구 또는 Julia-1 가중치 | 확인된 해당 자산 재사용 |

자막만 기록하는 분에게 음성 모델을 미리 받게 하지 않습니다. 중계를 선택하지 않으면 중계 도구도 받지 않습니다. 기록 엔진은 일부 파일만 나눠 받는 방식이 아니라 전체 묶음을 처음 준비합니다. 이전 판본의 엔진 용량을 새 묶음의 확정 용량으로 사용하지 않습니다.

## 인터넷과 취소

설치·각 도구의 첫 준비에는 인터넷이 필요합니다. 국회 자막 수신·외부 AI 정리·동료 중계에는 준비 후에도 인터넷이 필요합니다. 검증된 파일을 다시 쓰는 것과 완전한 오프라인 사용은 다릅니다.

진행 중 취소했다면 연결과 여유 공간을 확인한 뒤 다시 시도합니다. 완료하지 못한 임시 자료를 준비 완료로 표시하지 않으며 기존 기록과 이미 확인한 자료를 보존합니다. 업데이트가 다른 판본을 요구하면 새 자료를 준비할 수 있습니다.

## 개발·패키징 계약

- 기본 앱에는 엔진·CPU 모델·중계 CLI를 다시 넣지 않습니다. 모델 사용 조건과 제삼자 고지는 보존합니다.
- 엔진과 중계 도구를 먼저 묶고 각 파일·압축 자료의 고정 크기와 SHA256을 앱 카탈로그에 기록한 뒤 데스크톱을 빌드합니다.
- NSIS 웹 설치파일은 별도의 기본 앱 압축 자료를 받습니다. apply-web-installer-security.cjs가 고정된 electron-builder 26.18.0의 두 템플릿을 보완해 기존판 종료·제거 전에 소유 사본을 준비하고 SHA512를 검사합니다. 추출 직전에도 같은 사본을 재검사합니다.
- 인접한 자료나 명시한 --package-file도 검증을 생략하지 않습니다. 검증 실패·준비 취소를 전체 설치의 완전한 원자 롤백 보장이라고 표현하지 않습니다.
- 필요한 모든 기능을 선택하면 추가 다운로드와 저장 공간이 필요합니다. 최종 측정은 각 배포 자산과 설치 후 파일을 기준으로 별도 기록합니다.

기존 0.1.2는 엔진·중계·일부 음성 자산을 한 설치파일에 제공한 판본입니다. 기존 배포본과 0.2.0 준비판의 수치를 섞지 않습니다. 최종 공개 상태와 파일 확인값은 [배포 확인 정보](public-release/RELEASE_MANIFEST.json)를 따릅니다.


## 0.2.0 실제 빌드 결과

MB는 1,000,000바이트입니다. 설치 EXE만의 크기와 실제로 받는 전체 크기를 구분합니다.

| 구분 | 용량 | 받는 시점 |
|---|---:|---|
| 설치파일 | 0.77MB | 사용자가 처음 받음 |
| 기본 앱 | 114.03MB | 설치 중 자동 준비 |
| 기록 엔진 | 64.89MB | 기록 화면을 처음 열 때 |
| 중계 도구·사이트 자료 | 54.43MB | 중계를 처음 준비할 때 |

설치 시 실제 전송 합계는 **114.80MB**이며, 기존 0.1.2의319.41MB보다 **64.1% 감소**했습니다.
처음 기록 화면까지 준비하면 합계 **179.69MB**입니다.
기본 앱의 파일 합계는 **331.01MB**이고, 선택한 기능의 엔진·도구·모델 파일은 추가됩니다.
음성 모델·줄리아 가중치는 선택 준비이며 이 기본 전송량에 포함하지 않습니다.
인터넷 설치에 사용한 기본 압축 파일을 별도 영구 캐시로 남기지 않습니다.

전체 파일 해시를 유지한 실제 로컬 재사용 검증은 기록 엔진1.92초·중계도구8.30초였습니다. 장비와 저장장치에 따라 달라집니다.
실제 새 설치 실행·모델 추론 품질 비교는 이번 검증에서 반복하지 않았습니다.
