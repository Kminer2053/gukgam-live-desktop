# 설치파일 용량 검토 · 0.1.2

2026-11-03 Windows x64 실제 NSIS 산출물과 포함 파일의 바이트를 비교했습니다.
MB는 1,000,000바이트입니다. 설치 후 값은 파일 합계이며 디스크 할당 크기와 다릅니다.

| 구분 | 0.1.1 | 0.1.2 | 차이 |
|---|---:|---:|---:|
| 다운로드 | 325.88MB | 319.41MB | 6.48MB 감소(약 2%) |
| 설치 후 파일 합계 | 841.34MB | 849.34MB | 8.00MB 증가 |

앱 자체 코드보다 함께 제공하는 실행 환경과 음성 모델이 큽니다.
기존 0.1.1의 원본 구성은 Electron 373.99MB, 릴레이 배포 도구 175.89MB,
Python 엔진 153.88MB, 음성 모델·CPU 실행 도구 132.80MB였습니다.

## 이번에 반영한 정리

- Electron은 한국어·영어만 남겼습니다. 기존 설치물 기준 다른 언어 53개가 49.87MB였습니다.
- 새 릴레이 도구의 소스맵 544개·문서 291개를 정확한 경로로 제외했습니다(원본 10.37MB).
- 별도 라이선스가 확인되지 않은 README 11개와 라이선스·고지 247개는 보존했습니다.
- 모델 107.01MB와 CPU 실행 도구, Python·Electron, 실제 실행 코드·표준 선언 파일은 유지했습니다.

보안·호환성을 위해 교체한 CLI50은 기존 도구보다 원본이 69.59MB 큽니다.
그래서 불필요한 파일을 줄여도 전체 설치 후 용량은 소폭 늘었습니다.
다운로드와 설치 후 용량은 압축률 때문에 서로 다르게 변합니다.
새 설치파일 안의 모델·실행 코드·라이선스·제외 목록을 실제 바이트로 대조했습니다.

## 더 큰 절감이 필요할 때

1. **중계 도구를 선택 설치로 분리**: 혼자 기록하는 사용자는 필요할 때만 받을 수 있습니다.
   다운로드 출처·고정 해시·실패 시 재개·오프라인 설치 안내를 함께 구현해야 합니다.
2. **음성 기능을 선택 설치하는 별도 경량판**: 자막만 쓰는 사용자에게 효과가 큽니다.
   이번 기본판에 요청된 CPU 화자분리 모델은 그대로 유지합니다.
3. **앱 실행 환경 교체**: Electron·Python 의존도를 낮추면 더 크게 줄일 수 있으나
   로그인·보안 저장·기록 화면·패키징을 다시 검증해야 하는 별도 개발입니다.

위 세 항목은 검토안이며 이번 0.1.2에 구현됐다고 표시하지 않습니다.
TypeScript 중복본은 실제로 다른 모듈 경로에서 사용하고, 타 운영체제용 바이너리는
현재 묶음에 없어 단순 삭제 대상으로 삼지 않았습니다.
