# 국감 라이브 데스크톱 · 0.2.0 제품 안내와 보존 계약

0.2.0 경량 인터넷 설치판을 준비 중입니다. 이 문서는 예정된 사용 흐름과 구현 계약을 설명하며 실제 설치·공개 완료나 최종 용량을 대신하지 않습니다.

## 일반 사무담당자의 네 단계

1. 인터넷에 연결해 앱을 설치하고 기관 이름을 저장합니다.
2. 시작 화면의 **AI 연결**에서 본인 ChatGPT 계정으로 로그인합니다.
3. **기록 화면 열기**를 눌러 처음 필요한 기록 도구를 준비한 뒤 회의를 선택·시작합니다.
4. 검색·하단 시간 막대·질의 요약·후속조치를 이용하고 보고서로 저장합니다.

ChatGPT 기능과 사용량은 본인 계정·플랜·서비스 정책을 따릅니다. API 키를 쓰는 다른 AI는 별도 선택이며 요금도 별개입니다. 정리에 필요한 글과 문맥은 선택한 외부 AI로 전달됩니다.

## 필요한 기능을 처음 쓸 때 준비

| 구성 | 준비 시점 |
|---|---|
| 기본 앱 | 인터넷 설치파일이 시작 화면·계정 연결·설명서가 든 기본 앱을 받음 |
| 기록 엔진 | 기록 화면을 처음 열 때 전체 묶음을 받음 |
| 중계 도구 | 중계 연결·사이트 준비 기능을 처음 쓸 때 도구와 사이트 기본 자료를 받음 |
| 음성·추가 역할 판정 | 해당 기능을 선택하고 사용 조건을 확인한 뒤 준비 |

기본 앱에 엔진·중계 CLI·사이트 배포 자료·CPU 음성 모델을 미리 넣지 않습니다. 자막 수신에는 음성 모델이 필요하지 않으며 중계를 선택하지 않으면 중계 도구를 받지 않습니다. 검증된 같은 판본은 재사용하고 업데이트에 필요한 새 판본은 다시 준비할 수 있습니다.

설치와 첫 준비에는 인터넷이 필요합니다. 국회 자막 수신·ChatGPT 정리·동료 중계는 이후에도 인터넷을 사용합니다. 준비 파일을 취소하거나 다시 받는 일이 기존 회의 기록을 지우는 동작으로 이어지지 않아야 합니다.

## 내 PC의 기록과 선택한 공유

받은 원문과 정리 결과는 앱 전용 기록 폴더에 저장합니다. 사람이 고친 내용·검토한 요약·원문은 자동 처리로 덮어쓰지 않습니다. 필요한 기록은 보고서·단독 HTML로 따로 보관할 수 있습니다. 보존 기간 변경이나 명시적인 회의 삭제는 별도 동작입니다.

공유는 선택입니다. 시작일·종료일을 정해 중계하고 사용을 끄면 동료에게 전달하는 연결을 멈춥니다. PC의 기록·검색·AI 처리는 계속 사용할 수 있습니다. PC가 켜져 연결된 동안 원본을 열람하며 이전 서버 보관 자료의 자동 삭제나 호스팅 요금 종료와는 다릅니다.

## 관리자·개발자 참고

- 일반 직원에게 Python·Node.js·Git 설치나 터미널 실행을 요구하지 않습니다. Windows x64·Core i5급·메모리 16GB를 기준으로 준비합니다.
- 실행 도구의 URL·판본·크기·해시·파일 목록은 앱 빌드에 고정합니다. 네트워크 응답으로 임의 실행 경로나 새 주소를 받아 실행하지 않습니다.
- 선택 다운로드의 준비·취소와 실제 자식 실행을 구분하며 준비가 끝났다는 이유로 수집·음성 추론을 자동 시작하지 않습니다.
- 기존 기록·계정·개인 설정을 공개 소스나 다운로드 묶음에 넣지 않습니다. 자격증명은 OS 암호화 보관소와 소유한 익명 통로에서만 취급합니다.
- NSIS 웹 설치는 기존판 종료·제거 전 기본 앱 자료의 SHA512를 확인하고 추출 직전 다시 확인하도록 원본 두 템플릿을 보완합니다. 완전한 설치 롤백이나 운영체제 서명 검증을 같은 의미로 주장하지 않습니다.
- 빌드 순서는 고정 의존성·호환 보완 → Python 엔진 → 선택 다운로드와 카탈로그 → 데스크톱 → NSIS 웹 설치입니다. 최종 크기·해시·실제 설치 결과는 별도 검증합니다.
