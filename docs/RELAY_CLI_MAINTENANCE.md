## 반드시 보존할 동작

배포 링크는 일반 파일·최대 4096바이트인지 확인한다. symlink/junction, 경로 우회,
hardlink, 열린 핸들의 identity 변경, 팀·프로젝트 ID 불일치는 자식 실행 전에 거부한다.
명시 환경 바인딩과 배포 POST의 프로젝트 ID 보완이 모두 필요하다.
프로젝트가 삭제되거나 권한을 잃었을 때 새 프로젝트를 만드는 동작으로 전환하지 않는다.

인증은 `vercel-cli-auth`의 `{version:1, authJson}` 전체를 보호 저장소에 보관한다.
알 수 없는 확장 필드와 회전한 인증값도 보존하고, CLI와 REST 호출은 같은 직렬 큐를 쓴다.
전용 임시 인증 파일은 소유 자식의 종료를 확인한 뒤 정리한다.
종료 미확인은 안전한 취소나 재시도 가능 상태로 바꾸지 않는다.
원시 명령 출력·토큰·DB 연결값은 화면이나 진단 로그에 넣지 않는다.

DB 생성 결과가 불명확하면 `/v1/storage/stores`를 선택한 팀 범위로 조회한다.
`stores` 배열·ID·중복 ID를 검증하고, 작업 기록의 `resourceName`과 일치하는
정확히 한 항목만 연결한다. 목록 누락·복수 일치·손상은 기존 작업을 보존하며,
복구를 위해 프로젝트나 DB 생성 POST를 반복하지 않는다.
현재 어댑터는 이 목록을 한 번 조회하며 자동 페이지 순회는 구현하지 않는다.
향후 API가 페이지 단위 응답을 요구하면 공식 응답 계약에 맞춘 제한된 cursor 처리를
별도로 검증해야 하며, 현재 결과를 모든 페이지의 조회 증거라고 부르지 않는다.

기존 사이트 업데이트는 기록된 팀·프로젝트와 배포 결과의 프로젝트 ID를 대조한다.
사이트 로그인·DB·원본 PC 열람 모드를 확인한 뒤에만 새 URL을 저장한다.
암호·DB·다른 설정은 유지한다. 배포를 시도한 뒤 취소·오류가 나면 결과 미확인으로
남기고 이전 URL을 유지하거나 복원하며 자동 재배포하지 않는다.
현재 PC 확인은 소유 엔진의 JSONL 연결 식별자를 사용한다.
중계 도구 변경 때문에 실황 수집·녹음·AI 엔진을 정지하거나 재시작하지 않는다.

## 재현과 검증

Node.js 24 이상에서 저장소의 고정 lock을 사용한다. 설치·실행은 별도 승인된
개발 폴더에서 하며 실제 계정·운영 기록을 시험 자료로 쓰지 않는다.

```sh
cd desktop
npm ci --ignore-scripts
npm ci --prefix relay-cli --ignore-scripts
npm run prepare:compat --prefix relay-cli
npm test
npm run typecheck
npm run build
```

배포 빌드의 `predist`도 같은 고정 호환 보완을 검증한다.
원본·보완 해시나 라이선스가 다르면 중단하고, 임의로 guard 값을 낮추지 않는다.
이번 소스는 root 정상 실행 환경에서 Node **209건 통과**, 타입 검사·빌드 exit 0을
확인했다. 합성 시험은 실제 계정 로그인·토큰 갱신·클라우드 배포 성공의 증거가 아니다.

주요 회귀는 `vercel-cli`, `vercel-deploy-binding`, `relay-provisioner`,
`relay-site-update`, `relay-owned-connection`, `packaged-resources` 시험이다.
공식 CLI 패키지 자체의 원본→보완·반복 적용·변조 거부와 실제 POST 프로젝트 ID 전달도
별도 합성 계약으로 확인한다. agent 격리 환경에서의 상위 폴더 `EPERM`이나 esbuild 접근 거부는
원인을 기록하고 정상 실행 환경에서 재확인한다. 이를 통과시키려고 보호를 완화하지 않는다.

CLI50에는 `api` 명령이 없다. 기존 모의 시험의 `run(['api', ...])`는 자식 실행·직렬화·
입출력 보호의 시험 자료일 뿐 실제 CLI 기능의 증거가 아니다. 제품의 `requestApi()`는
공식 `whoami` 갱신 뒤 고정 `https://api.vercel.com`으로 직접 요청한다.
JSON 본문·헤더·팀 query·응답 상한·취소 계약은 이 어댑터에서 유지한다.
`curl` 명령이나 global `--api` 옵션으로 대신하지 않는다.

## 경량화 원칙

Electron 언어 자산은 한국어·영어만 동봉한다. CLI 필터는 확인된 비런타임 파일
835개의 정확한 경로와 개발용 `.cache`만 제외한다. lock 그래프와 버전은 그대로 유지한다.
필터 개수를 설치파일의 안전성이나 실제 절감 용량으로 대신하지 않는다.

CLI 진입점·동적 의존성·프로젝트 배포 빌더·Python 런타임·모델·필수 SQL/static·
원 LICENSE는 크기 목표 때문에 제거하지 않는다. 인증 파일·사용자 설정·기록·음성은
원래부터 배포 입력이 아니다. 설치 자산의 복사 필터와 동봉 실행 경로는 실제 패키지에서
따로 확인한다. 새 설치파일은 검증·게시가 끝나기 전까지 기존 정식 다운로드를 대체하지 않는다.
