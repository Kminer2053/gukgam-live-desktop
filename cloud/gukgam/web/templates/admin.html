{{ icon('mic', 'ic-sm') }}음성인식

국회에서 제공하는 자막은 음성 모델 없이 수집합니다. 직접 받은 음성을 전사할 때만 아래 선택 기능을 사용합니다.

이 앱의 음성 작업자에만 적용합니다. 내부 스레드 수 제한과는 다릅니다.

Nemotron 3.5 ASR로 음성을 전사하고, Nemotron 3 Diarization으로 녹음의 목소리별 발언 구간을 나눕니다. Julia는 전사된 글의 위원·답변·진행 역할 판정을 보조합니다.

전사 모델 741,548,352B, 화자 분리 모델 107,012,128B, CPU 실행 도구 5,528,418B가 필요합니다. 화자 분리 모델은 설치파일에 포함하며, 전사 모델은 준비 버튼으로 받습니다. 약 1.1GB 이상의 여유 공간과 AVX2 호환 CPU가 필요합니다. GPU·별도 Python·Node 설치는 필요하지 않습니다.

녹음 파일은 전체 음성에서 최대 8명의 목소리를 추적한 뒤 나누어 전사합니다. 화자 번호는 실명이 아니며, 겹쳐 말한 구간의 이름·내용은 확인이 필요합니다. MP3·영상은 변환 도구도 필요합니다.

중계·브라우저 음성도 빠른 CPU 설정으로 약 30초의 음성을 모아 화자를 나눕니다. 음성을 받는 동안 전사가 늦게 표시될 수 있으며, 처리 지연이 커지면 화자 표시를 보류하고 전사를 계속합니다.

모델 OpenMDW-1.1 라이선스 · 공식 모델·고정 판본 · CPU 실행 도구 Apache-2.0·제3자 고지
